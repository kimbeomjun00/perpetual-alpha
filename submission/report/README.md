# Technical report

`PA26-lifeisluck-report.pdf` is the final report prepared for submission to
Perpetual Alpha 2026. The accompanying `.tex` file and `live_results.png` are
included so that the report can be reproduced in a standard LaTex environment.

The figure uses the Hyperliquid Testnet public portfolio PnL history available
at the time the report was produced. It is labelled separately from the
competition's official daily snapshot score.
